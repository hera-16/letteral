## はじめに

### Letteralとは

Letteralは、企業向けの匿名進捗共有プラットフォームです。社員が日々の進捗・課題・学びを匿名で共有し、組織全体の透明性とコミュニケーションを促進します。

### 主な機能

- **匿名進捗投稿**: 実名を明かさずに進捗を共有
- **カテゴリー分類**: 成果・課題・学びを整理
- **OKR連携**: 目標達成度と進捗を紐づけ
- **組織階層管理**: 部署・チーム単位で情報を整理
- **レポート**: データに基づいた組織分析

## ログイン

### 初回ログイン

1. 管理者から送られたログイン情報を用意します
2. ブラウザでLetteralのURLにアクセス
3. ログイン画面でメールアドレスとパスワードを入力
4. 「ログイン」ボタンをクリック

```
URL: https://your-company.letteral.example.com
メールアドレス: your.email@company.com
パスワード: (管理者から提供されたもの)
```

### パスワード変更

初回ログイン後は、セキュリティのためパスワード変更を推奨します。

1. 画面右上のプロフィールアイコンをクリック
2. 「設定」を選択
3. 「パスワード変更」タブを開く
4. 現在のパスワードと新しいパスワードを入力
5. 「保存」をクリック

## 進捗投稿

### 新規投稿の作成

進捗投稿は、あなたの日々の仕事の成果・課題・学びを共有する機能です。

#### 手順

1. ダッシュボード画面で「進捗を投稿」ボタンをクリック
2. 投稿フォームに以下を入力:
   - **内容**: 進捗の詳細（必須）
   - **カテゴリー**: 成果/課題/学び/その他から選択
   - **公開範囲**: 全社/組織内/非公開を選択
   - **タグ**: 関連するキーワードを追加（任意）
   - **OKR連携**: 関連するOKRを選択（任意）
3. 「投稿」ボタンをクリック

#### カテゴリーの選び方

| カテゴリー | 説明 | 例 |
|----------|------|-----|
| **成果** | 達成したこと、完了したタスク | 「新機能リリース完了」「営業目標達成」 |
| **課題** | 直面している問題、困っていること | 「パフォーマンス問題が発生」「リソース不足」 |
| **学び** | 学んだこと、気づき | 「新しい開発手法を習得」「顧客インサイト」 |
| **その他** | 上記に当てはまらない内容 | 「チームミーティング実施」 |

#### 公開範囲の選択

- **全社**: テナント内の全ユーザーが閲覧可能
- **組織内**: 所属組織（部署・チーム）内のみ閲覧可能
- **非公開**: 自分とマネージャーのみ閲覧可能

### 投稿の編集・削除

1. 自分の投稿一覧から編集したい投稿を選択
2. 右上の「...」メニューをクリック
3. 「編集」または「削除」を選択

注: 投稿は作成後24時間以内のみ編集可能です。

### タグの活用

タグを使うことで、関連する投稿をグループ化し、後から検索しやすくなります。

推奨タグ例:
- プロジェクト名: `#新規サービス開発`
- 技術スタック: `#React` `#Java` `#AWS`
- チーム名: `#開発チームA`
- 期間: `#2025Q1`

## タイムライン

### タイムライン画面

タイムライン画面では、組織内の最新の進捗投稿を時系列で閲覧できます。

#### フィルター機能

画面左側のフィルターパネルで投稿を絞り込めます:

- **カテゴリー**: 成果/課題/学び/その他
- **期間**: 今日/今週/今月/カスタム
- **タグ**: 特定のタグが付いた投稿のみ表示
- **組織**: 特定の部署・チームの投稿のみ表示

#### リアクション

他のユーザーの投稿に対してリアクションできます:

- 👍 いいね
- 💪 応援
- 💡 参考になった
- 🎉 おめでとう

投稿の下部にあるリアクションボタンをクリックするだけです。

#### コメント

投稿に対してコメントを残すことができます:

1. 投稿をクリックして詳細画面を開く
2. 画面下部のコメント入力欄にテキストを入力
3. 「コメント」ボタンをクリック

注: コメントも匿名で投稿されます。

## OKR管理

### OKRとは

OKR (Objectives and Key Results) は、目標設定と進捗管理のフレームワークです。

- **Objective (目標)**: 達成したい定性的な目標
- **Key Results (主要成果)**: 目標達成を測定する定量的な指標

### OKRの作成

1. 左サイドバーの「OKR」をクリック
2. 「新しいOKR」ボタンをクリック
3. 以下を入力:
   - **目標タイトル**: 達成したいこと
   - **説明**: 目標の詳細
   - **四半期**: 目標期間（例: 2025-Q1）
   - **Key Results**: 測定指標を3〜5個追加

#### 例

**Objective**: 顧客満足度を向上させる

**Key Results**:
1. NPS (Net Promoter Score) を70以上にする (現在値: 55)
2. サポート対応時間を平均2時間以内にする (現在値: 4時間)
3. 顧客レビュー評価を4.5以上にする (現在値: 4.0)

### OKRの更新

1. OKR一覧から更新したいOKRを選択
2. 各Key Resultの「現在値」を更新
3. 進捗率が自動計算されます
4. 「保存」をクリック

### OKRと進捗投稿の連携

進捗投稿時にOKRを選択することで、目標と日々の活動を紐づけられます。

1. 進捗投稿フォームで「OKRに連携」をクリック
2. 関連するOKRを選択
3. 投稿を完了

連携された投稿は、OKR詳細画面で一覧表示されます。

## レポート機能

### ダッシュボード

ダッシュボードでは、組織全体の活動状況を一目で確認できます。

#### 表示される指標

- **今週の投稿数**: 今週投稿された進捗の総数
- **アクティブユーザー数**: 今週投稿したユーザーの数
- **カテゴリー別内訳**: 成果/課題/学び/その他の割合
- **人気のタグ**: よく使われているタグTOP 10
- **エンゲージメント率**: 投稿に対するリアクション・コメントの割合

### レポートの作成

詳細なレポートを作成し、CSV/Excel/PDF形式でエクスポートできます。

1. 左サイドバーの「レポート」をクリック
2. レポート期間を選択（開始日〜終了日）
3. フィルター条件を設定（組織、カテゴリーなど）
4. 「レポート生成」をクリック
5. 「エクスポート」ボタンから形式を選択

#### エクスポート形式

- **CSV**: データ分析用（Excel等で開ける）
- **Excel**: グラフ付きレポート
- **PDF**: プレゼンテーション用

## 組織管理

管理者およびマネージャー向けの機能です。

### 組織階層の設定

組織階層を設定することで、進捗の可視化範囲を制御できます。

#### 組織の作成

1. 管理画面で「組織管理」をクリック
2. 「新しい組織」ボタンをクリック
3. 以下を入力:
   - **組織名**: 部署・チーム名
   - **親組織**: 上位組織を選択（オプション）
   - **組織タイプ**: 本部/部/課/チーム
   - **説明**: 組織の役割や目的

#### 階層構造の例

```
会社
├── 開発本部
│   ├── フロントエンド部
│   │   ├── チームA
│   │   └── チームB
│   └── バックエンド部
│       ├── チームC
│       └── チームD
└── 営業本部
    ├── 第一営業部
    └── 第二営業部
```

### ユーザー管理

#### ユーザーの追加

1. 管理画面で「ユーザー管理」をクリック
2. 「新しいユーザー」ボタンをクリック
3. 以下を入力:
   - **メールアドレス**: ログイン用
   - **ユーザー名**: 表示名
   - **社員ID**: 社員番号（オプション）
   - **所属組織**: ユーザーが所属する組織
   - **役割**: USER / MANAGER / ADMIN

#### 役割の説明

| 役割 | 権限 |
|------|------|
| **USER** | 進捗投稿、閲覧、OKR作成 |
| **MANAGER** | USER権限 + 組織内レポート閲覧、メンバー管理 |
| **ADMIN** | MANAGER権限 + テナント設定、全組織管理 |
| **SUPER_ADMIN** | ADMIN権限 + システム設定（開発者用） |

## よくある質問

### Q1: 投稿は本当に匿名ですか？

**A**: はい、投稿者の名前は他のユーザーには表示されません。ただし、管理者は必要に応じて投稿者を確認できます（不適切な投稿への対処のため）。

### Q2: 過去の投稿を検索できますか？

**A**: はい、画面上部の検索バーからキーワード、タグ、期間で検索できます。

### Q3: スマートフォンから使用できますか？

**A**: はい、レスポンシブデザインに対応しており、スマートフォン・タブレットからアクセス可能です。専用アプリは現在開発中です。

### Q4: 通知機能はありますか？

**A**: はい、以下の場合に通知が届きます:
- 自分の投稿にコメントがついた時
- 自分の投稿にリアクションがついた時
- OKRの進捗率が目標値に達した時
- メンション（@ユーザー名）された時

通知設定は「設定」画面でカスタマイズできます。

### Q5: データはどのくらいの期間保存されますか？

**A**: すべてのデータは無期限で保存されます。ただし、プランによって保存容量の上限があります。

### Q6: パスワードを忘れた場合は？

**A**: ログイン画面の「パスワードを忘れた」リンクから、パスワードリセットメールをリクエストできます。

### Q7: Slackと連携できますか？

**A**: はい、PROプラン以上でSlack連携が利用可能です。新しい投稿を自動的にSlackチャンネルに通知できます。

詳細は管理画面の「インテグレーション」タブを参照してください。

### Q8: データのエクスポートは可能ですか？

**A**: はい、管理者権限があれば、すべてのデータをCSV/Excel形式でエクスポートできます。

### Q9: カスタマイズは可能ですか？

**A**: ENTERPRISEプランでは、ロゴ・カラーテーマ・カスタムフィールドなどのカスタマイズが可能です。

### Q10: サポート窓口はありますか？

**A**: はい、以下の方法でサポートをご利用いただけます:
- メール: support@letteral.example.com
- チャット: 画面右下のチャットアイコンからお問い合わせ
- 電話: ENTERPRISEプラン限定

営業時間: 平日 9:00-18:00 (土日祝日を除く)
